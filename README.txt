# 💌 Cápsula de Tiempo Digital

Una pequeña página romántica hecha únicamente con HTML, CSS y JavaScript.

## Estructura

capsula-tiempo/
├── index.html
├── style.css
├── script.js
├── img/
│   ├── foto1.jpg
│   ├── foto2.jpg
│   └── foto3.jpg
└── audio/
    └── musica.mp3

## Personalización

### 1. Fotos

Coloca tus fotografías dentro de `img/` con estos nombres:

- foto1.jpg
- foto2.jpg
- foto3.jpg

También puedes utilizar PNG o WebP, pero debes cambiar el nombre en el HTML/JS.

### 2. Música

Coloca tu archivo MP3 en:

`audio/musica.mp3`

Si tu canción tiene otro nombre, cambia la línea correspondiente en `index.html`.

### 3. Textos

Puedes modificar directamente los textos marcados con:

`<!-- CAMBIA ESTE TEXTO -->`

También puedes cambiar el contenido de las cartas dentro de `script.js`.

### 4. Contador

En `script.js` busca:

const fechaInicio = "2026-08-01";

y reemplázala por la fecha que quieras.

## Ejecutar

Puedes abrir `index.html` directamente en el navegador.

Para publicar:

- GitHub Pages
- Vercel
- Netlify

No necesita base de datos ni servidor.
